# System: Boats (Voyage)

**Depends on:** F2, F3 for crew  
**Effort:** Medium solo / High crew

## Design

- Equippable progression: raft → dinghy → boat → ship  
- Speed = swim-related + boat bonus + skill  
- Crew: standing-state reframe + crossbows (not swim combat unlock)  
- Player forward harpoon only (no multi-turret requirement)  

## Acceptance

- [ ] Solo equip/unequip stable on save  
- [ ] Crew does not softlock anim state  
- [ ] Research/upgrade path documented in FCS notes
