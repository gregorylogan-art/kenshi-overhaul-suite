# System: Fishing & water

**Package:** Survival  
**Depends on:** F1 (skill), F2 preferred (free-form), WSM economy optional  
**Effort:** Medium (High if F2 missing → use docks first)

## Player fantasy

Catch fish near shores and while swimming; sell, cook, or supply towns; garbage loot when unskilled.

## Design

- Rods / spears as items  
- 3s (or farming-like) chance roll while fishing action active  
- Base success ~25% + skill; garbage chance falls with skill  
- Free-form: swim state true → allow fish action  
- Docks: placeable buildings; storage mesh for fish  
- Recipes: fish → food / bait / trade goods  

## WSM

- Optional fish pressure per region  
- Job board “supply N fish to town X”

## Acceptance

- [ ] Can fish and receive item or garbage  
- [ ] Skill changes odds  
- [ ] Dock storage works  
- [ ] Does not require global water sim
