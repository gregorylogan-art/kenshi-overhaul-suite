# System: Towns & economy

**Depends on:** WSM  
**Effort:** Medium–High  
**Guardrail:** player-proximity simulation only

## Design

- Production schedules (logical)  
- Transfer to vendor stock  
- Job boards + bounty expansion  
- Optional visible haul when player present  

## WSM categories

Economy, Settlements, WorldEvents (offers)

## Acceptance

- [ ] Vendor stock changes after production tick near player  
- [ ] Job board gives modest reward  
- [ ] Far towns do not burn full CPU
