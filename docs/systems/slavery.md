# System: Slavery Deep

**Focus:** Player-as-slave (not full slaver empire)  
**Effort:** Medium–High

## Design

- Labor tasks while enslaved  
- Escapes: poison, food sabotage, keys/uniforms, informing  
- Faction rep → freedom / join  
- Broken status  
- Camp dialogue atmosphere  

## WSM

- Player slavery rep  
- Camp logical guards/prisoners for escape checks  
- Optional link to town production (slave labor abstract)

## Acceptance

- [ ] At least two non-run escape paths work  
- [ ] Rep path documented  
- [ ] Compatible with existing slavery-related mods noted in README of mod folder
