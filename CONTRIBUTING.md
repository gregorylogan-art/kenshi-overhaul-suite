# Contributing (solo + future collaborators)

1. Read `docs/vision/PRINCIPLES.md` and `docs/architecture/GUARDRAILS.md`.  
2. Scope changes update `docs/vision/SCOPE.md` in the same change set.  
3. Prefer small commits: one system or one spike.  
4. New expensive behavior behind `kos.*.enable` default 0.  
5. Document smoke tests in the commit message.  
6. Do not add global always-on simulation.  
7. Do not use “Kenshi 2.0” naming.
